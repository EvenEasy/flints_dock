# Graphical asset licensing

The Apache-2.0 license in [LICENSE](LICENSE) applies to the project’s source
code, scripts, configuration and documentation text. It does **not** grant a
reuse license for the project branding and artwork listed below.

Rights in these graphical materials are reserved by their respective rights
holders. Reuse, modification or redistribution requires permission from those
holders, except where an existing third-party license or applicable law permits
it. Permission for code does not supply permission for these images.
[BRANDING.md](BRANDING.md) separately governs presenting a product under the
Flint’s Dock identity.

The list identifies branding roles and concrete files; it does not establish
that every component is an original work owned by the project. The active PNG
art is documented as generated reconstruction from a supplied reference in
[art provenance](apps/app/assets/art/README.md) and
[generation.json](apps/app/assets/art/generation.json). Some images include
third-party marks, such as Solana. The project claims no ownership of those
marks. Original-reference authorship and permissions remain unverified; see the
[licensing audit](docs/licensing-audit.md). Rights are reserved only to the
extent held by the relevant holder, and existing third-party rights remain intact.
